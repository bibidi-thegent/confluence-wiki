# Confluence server wiki

The player wiki of the Confluence Minecraft server: how to join, the Player Guide's pages (classes and specs, the
world, professions), every command a player can use, the leaderboards and every update note.

- **Read it:** https://bibidi-thegent.github.io/confluence-wiki/
- **Build:** f08905a · 2026-10-28 (project commit `f08905a`, published 2026-10-28). The same stamp shows in every page's footer.

## These files are generated

Every file here is written by a tool in the server's private repository, from the Player Guide, the join guide, the
update notes and the game's own command list and boards. Each publish replaces the whole site, so an edit made here is
lost at the next one: changes belong in the private repository's sources.

- `index.html`: Start here. `join.html`, `commands.html`, `leaderboards.html` and `whats-new.html`: a page each.
- `classes/`, `world/` and `professions/`: the Player Guide's posts, a page each, with an `index.html` per section.
- `site.css`: the one stylesheet. There is no script, no web font and no request to any other site.
- `robots.txt`, and a robots tag on every page, ask search engines to leave the site out.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.
